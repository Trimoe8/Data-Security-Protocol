Privacy Policy

Late Thought Automation · last updated 24 November 2026

Late Thought Automation is a private tool. Its only user is the operator of the YouTube channel “The Late Thought”. It does not collect data from viewers or from any other person.

Data the tool accesses

With the operator's permission, the tool uses YouTube API Services to access the operator's own channel:

  • channel and video information (titles, descriptions, publishing status, public comments on the channel's videos),
  • aggregated channel statistics from YouTube Analytics and YouTube Reporting (views, watch time, retention, traffic sources, thumbnail impressions and click-through rate),
  • uploading the operator's own videos and thumbnails.

How the data is used and stored

  • The data is used only to plan, produce and evaluate videos for the operator's own channel.
  • It is stored only on the operator's own computer. It is not sold, shared with third parties or used for advertising.
  • Stored statistics and access tokens can be deleted at any time by the operator.

YouTube API Services

This tool uses YouTube API Services. Use is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page: myaccount.google.com/permissions. After revocation the tool can no longer access the channel. Locally stored data can then be deleted on request.

Contact

Questions or deletion requests: kontakt@example.com
